# Asciinema for LazyCat

Platform for hosting and sharing terminal session recordings.

- Homepage: https://asciinema.org
- HTTP service: port 4000
- PostgreSQL data is stored under `/lzcapp/var/postgres`.
- Asciinema data is stored under `/lzcapp/var/asciinema`.

The deployment wizard accepts an optional URL host. If it is left empty, the application uses the LazyCat assigned domain.
